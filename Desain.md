DESAIN.md — Huerstory

1. Identitas

Brand: HuerstoryTagline: You Live The Moment, We Capture The Story.

Huerstory adalah website Event Content Creator dengan fokus utama pada proses booking dalam satu halaman.

2. Warna

Gunakan tiga warna utama:

White: #FFFFFF — warna dasar halaman dan ruang kosong.

Pink: #ffcddb — aksen, highlight, selected state, dan elemen dekoratif.

Navy: #36346c — teks utama, heading, tombol utama, dan elemen penting.

Jangan menambahkan palet warna utama baru tanpa kebutuhan yang jelas.

3. Font

Gunakan dua font:

Poppins

Untuk:

navigation

body text

button

form/booking

label

harga

informasi umum

Tangerine

Hanya untuk:

aksen tulisan

kalimat emosional

decorative text

bagian kecil pada heading

Tangerine tidak digunakan untuk paragraf atau elemen yang membutuhkan keterbacaan tinggi.

7. Responsive

Website dibuat desktop-first, tetapi wajib responsive.

Target:

1440px desktop

1280px desktop

1024px laptop/tablet

768px tablet

375–430px mobile

Desktop menggunakan layout luas dan booking horizontal.

Mobile mengubah booking menjadi:

Event → Date → Package → Summary

Tidak boleh hanya mengecilkan layout desktop.

8. Motion

Gunakan animasi secara ringan dan fungsional:

fade in

slide/reveal

hover button

image hover

selected state

smooth section reveal

Animasi tidak boleh mengganggu proses booking.

9. Prinsip Utama

Desain harus terasa seperti website milik brand Event Content Creator yang dibuat secara sengaja, bukan template.

Booking adalah fokus utama. Branding mendukung booking, bukan menggantikannya.
